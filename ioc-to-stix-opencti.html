OpenCTI import utility

IoC → STIX Bundle Builder

Turn indicators copied from a threat report into an OpenCTI-ready STIX 2.1 bundle, linked to existing malware and/or MITRE ATT&CK techniques with “indicates” relationships.

Runs entirely in your browser — nothing is sent anywhere

Targets
What these indicators should link to — malware, attack pattern(s), or both. Provide at least one. Everything referenced here must already exist in OpenCTI — this tool never creates or edits Malware or Attack Pattern objects, so nothing already there is touched.
Used only in labels here and in the relationship description — never written to a Malware object.
One per line, optionally followed by a label. Every generated indicator gets an additional “indicates” relationship to each technique listed here.
Where do I find these STIX IDs?

Open the entity in OpenCTI, use its STIX2/JSON export (or the GraphQL API), and copy the id field. Malware IDs start with malware--; MITRE ATT&CK technique (attack pattern) IDs start with attack-pattern--. Using existing IDs instead of names means the relationships below attach to what you already have in OpenCTI, without creating or editing those objects.
