# OpenCTI-IoC-Importer
An HTML tool built using Claude Code that can import bulk indicators gathered from OSINT into Filigran's OpenCTI platform. 
Use-case: If an analyst finds multiple Indicators of Compromise (IoCs) from open sources (vendor reports, news articles, etc.), they can import them in bulk to OpenCTI. Useful if an attack pattern or malware object has been created, but no indicators have been added yet.
The program runs on the local host.
Requires the original Malware or Attack Pattern STIX ID from OpenCTI
